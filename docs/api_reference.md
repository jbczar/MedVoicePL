# API Reference

API documentation is auto-generated by FastAPI at runtime.

## Endpoints

Once the gateway is running, access the interactive API documentation at:

- **Swagger UI**: `http://localhost:8080/docs`
- **ReDoc**: `http://localhost:8080/redoc`
- **OpenAPI JSON**: `http://localhost:8080/openapi.json`

## Key Endpoints (Planned)

### Gateway

| Method | Path | Description |
|---|---|---|
| `POST` | `/api/v1/visit/start` | Start a new visit session |
| `POST` | `/api/v1/visit/{id}/upload-audio` | Upload visit audio recording |
| `GET` | `/api/v1/visit/{id}/status` | Get processing status |
| `GET` | `/api/v1/visit/{id}/results` | Get SOAP note + drug suggestions |
| `POST` | `/api/v1/visit/{id}/approve` | Doctor approves/modifies suggestions |

### On-Premise (Internal only)

| Method | Path | Description |
|---|---|---|
| `POST` | `/transcribe` | Audio → transcription |
| `POST` | `/structured-note` | Transcription → SOAP note |
| `GET` | `/health` | Health check |

### Cloud (Internal only)

| Method | Path | Description |
|---|---|---|
| `POST` | `/analyze` | Anonymized data → clinical analysis |
| `POST` | `/suggest-drugs` | Analysis → NFZ drug suggestions |
| `GET` | `/health` | Health check |
