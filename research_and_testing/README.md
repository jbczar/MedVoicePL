# Research & Testing

Evaluation environment for the MedVoicePL CDSS. Contains benchmarks, test cases, and analysis notebooks.

## Structure

- `test_cases/` — Golden test cases (clinical scenarios, expected outputs, audio fixtures)
- `evaluation/` — Evaluation scripts per module (STT, SLM, RAG, anonymization, system)
- `notebooks/` — Jupyter notebooks for analysis and visualization
- `scripts/` — CLI tools for running benchmarks and generating reports
- `results/` — Generated outputs (gitignored)
