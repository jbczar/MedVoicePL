# MedVoicePL
Multimodalny, wieloagentowy system hybrydowy do wspomagania decyzji klinicznych. Automatyzuje tworzenie notatek medycznych z wykorzystaniem lokalnego STT i SLM. Ponadto sugeruje leki wraz z refundacją NFZ poprzez chmurowy moduł RAG, zachowując przy tym pełną anonimizację danych pacjentów i zgodność z RODO.
